# Daylight downloads

Public distribution files for Daylight: signed and notarized macOS application ZIPs, checksums, release notes, and the Sparkle update feed. The application source is maintained in a separate private repository.

Download the latest available ZIP from Releases, extract it, and move Daylight into Applications. Future releases can be installed using Check for Updates inside Daylight.

Use development build 1.0.0-dev.11 or newer for the in-app updater. Older builds require one manual replacement.
